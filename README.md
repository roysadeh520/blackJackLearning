# בלאק ג׳ק לומדים

אתר בעברית מלאה (RTL) ללימוד ותרגול בלאק ג׳ק: שולחן קזינו וירטואלי עם דילר ושחקנים וירטואליים, מצב לימוד, מצב תרגול, משחק חופשי, תרגול מהיר, טבלת החלטות ומעקב התקדמות.

**האתר:** https://roysadeh520.github.io/blackJackLearning/

- אין הרשמה ואין התחברות. כל ההתקדמות נשמרת מקומית בדפדפן (פרופיל אנונימי).
- אין כסף אמיתי. כל הצ׳יפים וירטואליים בלבד.

## הרצה מקומית

```bash
npm install
npm run dev        # שרת פיתוח
npm test           # בדיקות יחידה למנוע המשחק ולמנוע ההחלטות
npm run build      # בנייה לתיקיית dist
npm run preview    # הצגת הבנייה
BASE_URL=http://localhost:4173/ npm run e2e   # בדיקת קצה לקצה בדפדפן (דורש Chromium)
```

## ארכיטקטורה

| שכבה | מיקום | תפקיד |
| --- | --- | --- |
| מנוע המשחק | `src/engine/` | קלפים, Shoe אמיתי (חפיסות, ערבוב, נקודת חיתוך), חוקי שולחן, מהלך סיבוב, תשלומים |
| מנוע ההחלטות | `src/strategy/basicStrategy.ts` | אסטרטגיה בסיסית לפי חוקי השולחן; המלצה, חלופה ודירוג החלטה |
| מנגנון ההסברים | `src/strategy/explanations.ts` | הסברים קצרים ומפורטים בעברית לפי המצב |
| שחקנים וירטואליים | `src/bots/` | שמות, דמויות, אישיות (מקצועי, מתחיל, זהיר, אגרסיבי) |
| סטטיסטיקות | `src/stats/profile.ts` | פרופיל מקומי, החלטות, טעויות, הישגים, היסטוריה |
| שמירת נתונים | `src/storage/` | ממשק `StorageAdapter`; כיום `localStorage`, ניתן להחלפה בסנכרון ענן |
| צלילים | `src/media/sound.ts` | צלילים מסונתזים (Web Audio) |
| ממשק המשתמש | `src/ui/` | מסכים, רכיבים, ובקר שולחן (`useTableController`) |

חוקי השולחן מוגדרים ב־`src/engine/rules.ts` (מספר חפיסות, 17 רך, הכפלה אחרי פיצול, פרישה, יחס תשלום) וכל המנועים קוראים מהם.

## פרסום

כל דחיפה ל־`main` מריצה בדיקות, בונה ומפרסמת לענף `gh-pages` (ראו `.github/workflows/deploy.yml`). האתר משתמש בניתוב hash ובנתיבי נכסים יחסיים, כך שהוא עובד תחת `/blackJackLearning/` גם בטעינה ישירה ובריענון.
